# Diego Photo — Matched Pair Print Spec

**Use:** This photo IS the emotional payload of the case. Esther (the player) plays the Diego ghost role and is providing her own photo as the source asset. Two prints will be made from the same file: one loose 4x6 that lives in Gloria's tote (surfaces during the R3 reveal as evidence of her motive), and one wallet-card-sized copy carried in Marco's billfold (Fiona produces it during R3 when she goes through Marco's wallet). The reveal only lands if the audience can compare the two prints in the same beat and see they match — same person, same image, mother and son both carrying him. **THE LOAD-BEARING RULE: BOTH PRINTS ARE THE SAME IMAGE, IDENTICALLY PROCESSED.** Any color correction, sepia tone, contrast adjustment, or crop applied to one MUST be applied to the other. If one is sepia, both are sepia. If one is cropped tight, both are cropped tight. No exceptions.

**Source asset**
- Esther provides a head-and-shoulders photo of herself. Confirm receipt of the source file at least **48 hours before the party**.
- Crop to head/shoulders if not already framed that way. Apply the SAME crop to both prints.

**Color treatment**
- Light vintage feel: a touch of warm tone OR a soft sepia OR muted/desaturated color. Pick one treatment and commit.
- Whatever you do to one print, do to the other in the same export. Export both prints from the same source file in the same session.
- Do NOT process the wallet card separately from the 4x6. One file → two print sizes.

**Print 1 — Loose 4x6 (Gloria's tote)**
- Size: ~4 x 6 inches.
- Stock: matte photo paper.
- No border, or a thin (1/8 in) white border — match border choice on the wallet card.
- Lives loose in Gloria's tote bag. Slight tote-bag wear is fine. Do not pre-distress.

**Print 2 — Wallet card (Marco's billfold)**
- Size: standard credit-card / wallet-card, **2.125 x 3.375 inches**.
- Stock: matte photo paper, same as the 4x6.
- Same image, same crop, same color treatment as the 4x6. Same source file. Same export session.
- **Aging instructions (after printing):**
  - Rub the four corners gently with the pad of your thumb until the matte slightly burnishes — soft wear, not damage.
  - Optional: one soft fold across the horizontal middle so the card sits naturally in a billfold. Do not crease hard. The fold should look like time, not vandalism.
  - Slip into Marco's billfold ahead of the party so it picks up a little leather warmth.

**Framing rule (repeat)**
- BOTH PRINTS MUST BE THE SAME IMAGE.
- BOTH PRINTS MUST USE THE SAME COLOR TREATMENT.
- BOTH PRINTS MUST USE THE SAME PAPER STOCK.
- The R3 reveal beat ("Fiona pulls the wallet card; Gloria's loose photo is already on the table") only lands if the audience can hold the two prints up together and see, instantly, that they are the same picture of the same person.

**Before the party — checklist**
- [ ] Confirm with Esther 48+ hours out that she has sent the source image.
- [ ] Confirm crop and color treatment with Esther (one round of yes/no, no design-by-committee).
- [ ] Export both sizes from the same source file in the same session.
- [ ] Dry-run the print on cheap paper first; check that color/tone matches between the 4x6 and the wallet-card crop.
- [ ] Print final on matte stock. Both prints, same session, same printer settings.
- [ ] Age the wallet card (corners, optional fold). Do NOT age the 4x6.
- [ ] Pre-load the wallet card into Marco's billfold the morning of the party.
- [ ] Pre-load the 4x6 into Gloria's tote bag the morning of the party.
