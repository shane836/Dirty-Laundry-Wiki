## What's NOT in this folder

These items are also in the props list "Print jobs" section but live elsewhere in the repo because they're managed by their own pipelines:

- **Character dossiers** — `dossiers/` folder, generated to PDF via `revise_dossiers.py` / `make_master_storyline_docx.py`.
- **The original by-round round cards** — `round cards/` folder. The per-player packets in section 06 of this folder are the ones to print; the original by-round files are the source-of-truth host references.

Print those from their own folders. Everything else for the print shop is in this directory.
