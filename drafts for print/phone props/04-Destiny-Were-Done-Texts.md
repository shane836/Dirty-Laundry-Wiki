# Destiny's "We're Done" Text Screenshots — Print Spec

**Use:** Destiny is an influencer. She screenshots everything. In Round 2 she "happens to have" four screenshots showing Paloma sent the **exact same breakup/cutoff message** — *"we need to talk. we're done."* — to four different people in April. Reframes the room: at least four people had a Paloma-shaped reason to be angry tonight. Hides the real motive (Gloria) by widening the suspect pool.

**Layout notes**
- Four mock iMessage screenshots stacked vertically on one 8.5x11 page. Each ~2"x4" (portrait phone aspect).
- Each screenshot has: status bar (time, signal/wifi/battery icons), contact name centered at top in bold, single outgoing message bubble (right-aligned, iMessage **blue** for #1 and #4, **green SMS** for #2 and #3 — hint that some of these recipients aren't on iPhone), timestamp above the bubble, "Delivered" or "Read [time]" receipt below.
- All four bubbles say the **identical** text: `we need to talk. we're done.`
- Vary the dates — all in April [event year = 2026] — and times so it's clear it's the same line on rotation, not a thread.
- Use **SF Pro** or system-UI font for the iMessage chrome (Helvetica Neue is acceptable). Text is lowercase as Paloma writes it.
- Optional: small "screenshot" border / subtle drop shadow around each phone-screen rectangle.
